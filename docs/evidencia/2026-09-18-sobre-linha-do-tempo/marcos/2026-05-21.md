**Pensava-se** que a ligação à instância do Claude Code, escrita no código em Abril, se mantinha.
**Descobriu-se** que o robô do Lovable tinha reescrito essas linhas de volta para a instância do Lovable.
**Mudou:** ninguém deu por isso. O site continuou a funcionar, pois a instância do Lovable continuava a receber notícias todas as manhãs.

Foi ao ler o histórico das alterações do código que se descobriu que o Lovable, quando está ligado a uma base de dados na sua cloud, pode reescrever a ligação do site para essa base sempre que se trabalha no editor, mesmo numa sessão só de planeamento. Por outras palavras: o robô da ferramenta gravou uma alteração de três linhas, as que dizem ao site a que base de dados se liga, e o site voltou a ler e a escrever na instância do Lovable. O processo automático não foi tocado, porque a ligação dele está noutro sítio. Durante os dois meses que se seguiram, o site serviu uma base de dados e o processo automático escreveu noutra, sem que nada parecesse partido.
