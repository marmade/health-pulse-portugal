**Pensava-se** que a ligação à instância do Claude Code, escrita no código em Abril, se mantinha.
**Descobriu-se** que o robô do Lovable tinha reescrito essas linhas de volta para a instância do Lovable.
**Mudou:** o site voltou a ler da instância do Lovable, e o processo automático continuou a escrever na do Claude Code. A partir daqui, cada um passou a trabalhar numa base de dados diferente. O site continuou a funcionar, porque a instância do Lovable continuava a receber notícias todas as manhãs.

Foi ao ler o histórico das alterações do código que se descobriu que o Lovable gravou uma alteração que mudou a base de dados a que o site se ligava, e o site voltou a ler e a escrever na instância do Lovable, o que fez o site mostrar valores de pesquisa errados.
